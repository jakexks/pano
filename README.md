# Pano

Build output of a private, in-browser 360° panorama viewer, served with GitHub Pages.

**Live:** https://jakexks.github.io/pano/

- `index.html`: the whole app (JS, CSS, fonts and icons inlined)
- `venice-sunset.jpg`: demo panorama, [Venice Sunset](https://polyhaven.com/a/venice_sunset) by Poly Haven (CC0)

Open a panorama from the web with `?src=`, e.g. `https://jakexks.github.io/pano/?src=https://example.com/pano.jpg`.
